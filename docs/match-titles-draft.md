# NFTI × NFTI 组合称号表（设计草稿 v1）

> 用途：默契度功能「组合称号」规则数据源（后续实现 matchRules.ts 的依据）
> 基准：**对称**（A×B 与 B×A 同称号）+ **双向特例**（约 20 对高传播组合单独写反向版）
> 唯一组合共 190 对（19 人格含 3 隐藏），已全部覆盖；本表含 193 格手写 + 镜像规则
> 风格：损行为不损人，校园真实画面，有梗不冒犯

## 一、矩阵镜像规则

- 默认：`title(A, B) = title(B, A)`，取表中任意方向
- 例外：见「四、双向特例」（这些组合反向展示不同称号）
- 隐藏人格兜底：`南方乱码 × 任何人` 若无手写条目，用"乱码"主题兜底称号（见二-3 行）
